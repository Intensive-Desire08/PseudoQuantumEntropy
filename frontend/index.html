06 / SPECIFICATIONS & DESIGN

Architecture & How It Works

Detailed engineering breakdown of the PseudoQuantum hybrid entropy extraction model, debiasing firmware, and cryptographic subsystem.

PHYSICAL LAYER

Dual-Photodiode Quantum Shot Noise

True quantum randomness arises from photon arrival statistics governed by Poisson processes. Two reverse-biased PIN photodiodes convert quantum optical shot noise into microvolt fluctuations.

  • ADC Pins: ESP32 GPIO 34 (Channel 1) & GPIO 35 (Channel 2).
  • Common Mode Rejection: Subtraction of Ch1 - Ch2 cancels ambient light flicker and thermal fluctuations.
  • Sampling Frequency: Continuous high-frequency ADC acquisition via hardware timer.
ALGORITHMIC LAYER

Backend LFSR Whitening & Processing

To minimize microcontroller compute overhead and avoid discarding bits in MCU firmware, the ESP32 streams raw digitized noise packets ([0xAA][0x55] + 64-byte payload). Whitening is executed entirely within the C++ backend:

  • Galois LFSR: 32-bit linear feedback shift register using primitive polynomial (taps at 32, 31, 29, 1, 0; 0x80000057).
  • Byte Whitening: Each raw byte is XORed with a dynamically clocked LFSR state mask (rawByte ^ mask).
  • Zero MCU Overhead: Firmware throughput is maximized with constant baud rate and predictable chunk sizing.
  • Source Agnostic: Whitened hardware entropy and OpenSSL fallback entropy both feed the thread-safe collector pool.
BACKEND SUBSYSTEM

Thread-Safe Ring Buffer & Fallback

The C++17 backend decouples hardware collection from consumer requests via a thread-safe entropy pool:

  • Background Collector: Runs continuous polling worker thread with auto-refill triggers.
  • Graceful Fallback: If serial disconnects or hardware is unavailable, seamlessly pivots to OpenSSL RAND_bytes().
  • Zero Blocking: Fast REST API reads directly from pool buffer with sub-millisecond response times.
CRYPTOGRAPHY LAYER

AES-256-GCM & Key Derivation

Cryptographic operations implement industry best practices:

  • Authenticated Cipher: AES-256 in Galois/Counter Mode (GCM) guarantees both confidentiality and ciphertext integrity.
  • Hardware-Backed IV: 96-bit Initialization Vectors drawn directly from the entropy pool to prevent IV reuse.
  • Key Derivation: PBKDF2-HMAC-SHA256 with 100,000 iterations and random salt.
